# Relationship between Races with Disability, Tobacco, and Mental Health CSE Project
When downloading all the data, rename all the csv files, to the following in order for the program to read the files properly:
  Race_and_Ethnic_Disparities_in_Cigarette_Smoking_Among_Adults_20260817 -> Cigarette_Smoking_Among_Adults
  DHDS_-_Prevalence_of_Disability_Status_and_Types_by_Demographic_Groups,_2021_20260817   -> DHDS
  Youth_Risk_Behavioral_Surveillance_System_(YRBSS)_-_Mental_Health_Indicators_20260817   -> Mental_Health_Indicators
  Run the data_processing.py file first before running the plotting.py file.
